## ✨ Overview

This portfolio showcases production web applications, accessible design systems, and case studies engineered with semantic HTML5, modern SCSS architectures, and vanilla JavaScript. Blending **18+ years of high-empathy customer leadership** with **academic excellence** (4.0 GPA at Austin Peay State University pursuing a B.S. in Computer Information Technology; 3.8 GPA in Business Administration from AIU; 3.4061 transfer coursework at APUS).

### 🌟 Key Highlights
- **100% Semantic & Accessible**: Strictly adheres to WCAG 2.1 AA guidelines, skip links, keyboard navigation focus rings, and screen-reader semantics.
- **Interactive SASSy CLI Easter Egg**: A fully functional browser terminal (`Ctrl+K` or `Cmd+K`) with custom commands like `bio`, `education`, `skills`, `shysti`, and `sudo hire-summer`.
- **Zero-Bloat Performance**: Built with pure native browser technologies—ultra-fast load times with zero third-party framework bloat.
- **Dual Theme Engine**: Supports both **Neon Noir** (dark mode) and **Luxe Daylight** (light mode) with persistent preference storage.
- **Deep-Dive Case Study Modals**: Rich, interactive component breakdowns detailing design problems, engineering solutions, and business outcomes.
